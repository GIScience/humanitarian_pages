## About Tram Tracks on Streets

Maps tram tracks running along streets. Where rails are set into the road surface they are a well-known hazard for people cycling, so this indicator serves primarily as a hazard map.

### How to read these results

Tracks come from OpenStreetMap. The reliable default is all tram tracks (railway=tram); an opt-in layer isolates rails explicitly tagged as embedded in the carriageway (embedded_rails), which is the precise cycling hazard but only patchily tagged. These are line features, so the indicator counts track segments and shows them on a map rather than measuring track length — the map is the deliverable, and segment counts should not be read as a density. Coverage depends on local tagging conventions.
